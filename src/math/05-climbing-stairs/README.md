# 70. Climbing Stairs

**Difficulty**: Easy
**Topics**: Math, Dynamic Programming, Memoization


---


## Problem Statement

## Descripción

Estás subiendo una escalera que tiene `n` peldaños.  
En cada paso puedes subir **1** o **2** peldaños.

Tu objetivo es calcular **de cuántas formas distintas** puedes llegar hasta la cima.

Este ejercicio es un clásico problema de programación dinámica y se asocia frecuentemente con la sucesión de Fibonacci.


---


## Ejemplos

### Ejemplo 1

```ts
Input: n = 2;
Output: 2;
```


---


## Complexity

- **Time Complexity**: O(n)
- **Space Complexity**: O(1)
